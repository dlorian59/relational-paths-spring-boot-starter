Версия добавляет лимиты из properties, условное создание JoinPlanner, приоритет
пользовательских beans, краткий фасад RelationalQueries и запускаемый отчёт с явным выбором адреса. Используется
Java 17 без preview API. На 21, 25 и 27 дополнительные возможности языка не требуются.
Основная библиотека сохраняет независимость от фреймворка.
